# Private AI Room

A private AI workspace connecting:

- 👤 Human
- 🤖 ChatGPT
- 💜 Gemini

## Vision

Private AI Room is designed as a private digital room for:

- Real-time AI conversations
- Text chat
- Voice interaction
- File sharing
- Shared project memory
- Conversation recovery
- Cloud backup
- Telegram access

## Core Requirement

The complete conversation history must be preserved and recoverable without omissions or errors.

## Current Stack

- Python
- Flask
- Docker
- Telegram Bot
- Gemini API
- Google Drive
- Render

## Project Status

🚧 Early development

Current backend provides:

- Basic web server
- Health check endpoint
- Docker deployment support

AI and Telegram integrations will be added progressively.

## Deployment

The backend is designed to run on Render.

## Security

API keys, Telegram bot tokens, and other secrets must never be committed to GitHub.

Secrets should be stored as environment variables.
